# ⚔️ Dragon's Escrow dApp

*"Not all those who wander are lost — but all ETH sent is recorded."* 🐉

A decentralized invoice management system built on Ethereum Sepolia Testnet, themed after The Hobbit: The Desolation of Smaug. Built for MG3012 Blockchain Technology (Fall 2026).

---

## 🏔️ What it does
- Forge invoices with a reference, payee address & ETH amount
- Send payment — gold travels directly to the payee via smart contract
- Look up any invoice by ID to check its status on-chain

---

## 🗝️ How to run
1. Open `index.html` in Chrome
2. Switch MetaMask to **Sepolia** test network
3. Click **Connect MetaMask** and enter the realm
